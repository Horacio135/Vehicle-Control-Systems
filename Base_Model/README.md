# Longitudinal base model

[← Repository](../README.md)

Vehicle parameters, longitudinal dynamics and a simple PI speed controller. The coursework scenario accelerates from rest over the first 75 m and brakes to stop before 100 m.

- `Base_Model.mlx`: original Live Script.
- `Base_Model.m`: readable MATLAB script.

This coursework model is separate from the four-wheel plant developed in [PROJECT](../PROJECT/README.md).
