Use [reproduce_run.m](../../Tools/reproduce_run.m) to regenerate a campaign without autoplay. It creates a temporary copy and disables only animation startup; it does not automatically render a new MP4. Full-resolution regenerated data is saved in the user-selected output directory. Published historical metrics come from saved runs, not from simulations rerun during documentation publication.
