# README structure references

[← Documentation](README.md)

The following public repositories were reviewed on **22 November 2026** for presentation and navigation patterns. They are formatting references, not imported code, physical-model validation or project affiliations.

| Reference | Pattern applied here |
|---|---|
| [F1TENTH Gym](https://github.com/f1tenth/f1tenth_gym/blob/main/README.md) | A short purpose statement, visible development status, direct quick-start steps and a documentation entry point |
| [MathWorks Vehicle Dynamics, 14 DOF](https://github.com/mathworks/Vehicle-Dynamics-14DOF-Simscape-Multibody) | Show the simulation purpose and visual overview before detailed model sections; provide a clear entry file |
| [MathWorks Vehicle Path Tracking with MPC](https://github.com/mathworks/vehicle-model-predictive-control) | Separate workflow, directory map, requirements and execution instructions |
| [CommonRoad IO](https://github.com/CommonRoad/commonroad-io/blob/develop/README.md) | Distinguish reproducibility, tested environment and links to deeper documentation |

The resulting layout uses an original project banner, a small number of factual status badges, quick navigation, requirements, scenario tables, result comparisons and explicit limitations. Detailed derivations and the full history remain in linked subpages rather than overwhelming the repository landing page. No licence, CI-success or physical-validation badge is claimed without supporting evidence.
